# Vacate

Menu bar app that quits an app when you close its last window, instead of letting it sit in the background doing nothing.

Click the menu bar icon to toggle it on/off, or exclude specific apps from being auto quit.

Needs Accessibility permission to know when windows close.

## Requirements

- macOS 13.0 (Ventura) or later.

## Install

Download the latest DMG from [Releases](https://github.com/SternXD/Vacate/releases/latest), open it, and drag Vacate to Applications.

If macOS blocks the app, allow it under **System Settings** -> **Privacy & Security**.

## Build

Open `Vacate.xcodeproj`, run the Vacate scheme.
